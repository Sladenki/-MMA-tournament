# Секретарь турнира по ММА

Локальная программа вместо Excel-файла «MMA_2024 программа взвешивания». Ведёт турнир от списка участников до протоколов и командного зачёта. База — один файл SQLite на ноутбуке секретаря, интернет не нужен.

## Запуск

Двойной щелчок по `start.bat` или в терминале:

```
pip install -r requirements.txt
python run.py
```

Откроется браузер: http://127.0.0.1:8765

## Как работать в день турнира

1. **Реквизиты** — название, дата, город, судьи, возрастные группы, дивизионы, веса, очки.
2. **Участники** — ручной ввод или импорт XLSX (колонки как в старом файле). Кнопка «Пример 14.09.2024» подставляет 14 человек из разобранной книги.
3. **Взвешивание** — фактический вес (запятая или точка), статус допуска, история перевзвешивания.
4. **Категории** — «Разбить на категории». Кто не попал в группу/дивизион/вес, попадает в отчёт «не размещены», а не пропадает.
5. **Сетки / Бои** — клик по паре, победитель и характер победы. Победители идут дальше сами. Исправление пересчитывает следующие туры.
6. **Итоги** — места, очки, командный зачёт, мандатная комиссия.
7. **Документы** — печать в PDF из браузера, выгрузка XLSX, резервная копия всего турнира в JSON.

Автосохранение после каждого действия. Кнопка «Отменить» откатывает последнее изменение.

## Правила (как в старом файле, без его дыр)

- Возраст: подпись `2007-2008`, `младше N` или `N+` (год рождения ≥ N, как в макросе).
- Дивизион: буква в поле разряда, иначе пусто/КМС/МС → первый, «1»/«2» → второй. Нераспознанный разряд — в «не размещены».
- Вес: первая граница ≥ веса. Перебор верхней границы не уходит молча в супертяж — пишется в отчёт.
- Жребий внутри категории, журнал с зерном генератора.
- Сетка: 0 / 1 / 2 / 3 (круг) / 8 / 16 / 32 / 64. При n > 64 — явная ошибка.
- Две бронзы по умолчанию (оба проигравших полуфинал — 3-е место). Бой за 3–4 включается в реквизитах.
- Очки по умолчанию: 10 / 8 / 6 / 2 / 1 / 0, настраиваются.
